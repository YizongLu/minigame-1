# Minigame 1
## Devlog
I think Components, GameObjects, and Scenes are like houses, cities, and counties. Components are like houses, and different houses can have different purposes and functions. A GameObject is like a city that contains many houses, and these houses contribute to how the city works. A Scene is like a country that contains multiple cities. All these cities come together to form a larger environment as a country.
